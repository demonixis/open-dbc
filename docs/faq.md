# FAQ

## Does OpenDBC include DarkBASIC?

No. It contains no DarkBASIC Classic help, examples, media or binaries; you run
your own programs. The DarkBASIC Professional help examples it includes come from
the MIT-licensed Dark-Basic-Pro repository ([NOTICE.md](NOTICE.md)).

## Is it related to comma.ai's opendbc?

No. comma.ai's `opendbc` is a collection of CAN bus `.dbc` files for cars. Here
DBC stands for DarkBASIC Classic; the two projects only share a name.
