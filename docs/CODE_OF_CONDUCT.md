# Code of conduct

OpenDBC follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in its issues, pull requests, discussions and every other project space.

Report unacceptable behaviour privately to the maintainer, Yannick Comte, by
e-mail at the address shown on the [demonixis](https://github.com/demonixis) GitHub profile.
Reports are kept confidential.
